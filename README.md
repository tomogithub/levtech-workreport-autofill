# LevTech Workreport Autofill

LevTech Platformの作業報告書入力画面で、開始時間、終了時間、休憩時間、作業内容をまとめて入力するChrome / Edge向け拡張機能です。

## できること

- `10:00` のような24時間表記で勤務時間を入力
- 作業内容を全対象日にまとめて入力
- 土日を除外
- 入力済みの日をスキップ、または上書き
- 入力後に作業時間と月次合計の表示を更新

## インストール

### Chrome

1. `chrome://extensions/` を開く
2. 右上の「デベロッパー モード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このフォルダを選択する

### Microsoft Edge

1. `edge://extensions/` を開く
2. 左側または右側の「開発者モード」をONにする
3. 「展開して読み込み」を押す
4. このフォルダを選択する

## 使い方

1. LevTech Platformで作業報告書の作成・編集画面を開く
2. ブラウザ右上の拡張機能アイコンから「勤怠自動入力」を開く
3. 開始時間、終了時間、休憩時間、作業内容を入力する
4. 必要に応じて「土日を除外する」「入力済みの日も上書きする」を切り替える
5. 「この月に入力する」を押す
6. 内容を確認して、問題なければ画面側の「保存する」を押す

## 初期値

- 開始時間: `10:00`
- 終了時間: `19:00`
- 休憩時間: `01:00`
- 作業内容: `開発業務`
- 土日除外: ON
- 上書き: OFF

## 対象ページ

`https://platform.levtech.jp/p/workreport/input*`

フォーム構造は、いただいたHTMLの以下の入力欄を対象にしています。

- `ref="start_time"`
- `ref="end_time"`
- `ref="relax_time"`
- `name="data[DailyReport][YYYYMMDD][work_content]"`

## 注意

この拡張機能は入力補助だけを行います。自動保存や自動送信はしません。入力後は必ず画面上で内容を確認してから保存してください。
