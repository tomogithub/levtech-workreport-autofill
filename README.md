# LevTech Workreport Autofill

LevTech Platformの作業報告書入力画面で、開始時間、終了時間、休憩時間、作業内容をまとめて入力するChrome / Edge向け拡張機能です。

## できること

- `10:00` のような24時間表記で勤務時間を入力
- 作業内容を全対象日にまとめて入力
- 土日・祝日を除外
- 入力済みの日をスキップ、または上書き
- 作業時間と月次合計は画面側で自動再計算されます

## インストール

### Chrome

1. `chrome://extensions/` を開く
2. 右上の「デベロッパー モード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. このフォルダを選択する

### Microsoft Edge

1. `edge://extensions/` を開く
2. 左側または右側の「開発者モード」をONにする
3. 「展開して読み込み」を押す
4. このフォルダを選択する

## 使い方

1. LevTech Platformで作業報告書の作成・編集画面を開く
2. ブラウザ右上の拡張機能アイコンから「勤怠自動入力」を開く
3. 開始時間、終了時間、休憩時間、作業内容を入力する
4. 必要に応じて「土日・祝日を除外する」「入力済みの日も上書きする」を切り替える
5. 「この月に入力する」を押す
6. 作業時間・合計が更新され「保存する」ボタンが押せるようになったことを確認し、問題なければ画面側の「保存する」を押す

## 初期値

- 開始時間: `10:00`
- 終了時間: `19:00`
- 休憩時間: `01:00`
- 作業内容: `開発業務`
- 土日・祝日除外: ON
- 上書き: OFF

## 対象ページ

`https://platform.levtech.jp/p/work-report/{ID}/`（作業報告の詳細画面）

画面はページ遷移なしで切り替わる作りのため、コンテンツスクリプトは `https://platform.levtech.jp/p/*` で読み込み、ボタン押下時に入力欄の有無を判定します。

対象の入力欄（`{n}` は行番号）:

- `name="rows.{n}.startTime"`（開始時刻）
- `name="rows.{n}.endTime"`（終了時刻）
- `name="rows.{n}.breakTime"`（休憩等時間）
- `name="rows.{n}.comment"`（作業内容）

土日・祝日は日付セルの `*_labelSaturday` / `*_labelHolidayOrSunday` クラスで判定します。

ポップアップに「作業報告の詳細画面で開いてください」と出る場合は、ページを再読み込みしてから再度開いてください。

## 注意

この拡張機能は入力補助だけを行います。自動保存や自動送信はしません。入力後は必ず画面上で内容を確認してから保存してください。

## 権限と公開前の確認事項

- 拡張機能が保存するのは、開始時間・終了時間・休憩時間・作業内容などの入力設定だけで、保存先はブラウザのローカルストレージです。
- 外部サーバーへの送信処理は含まれていません。対象ページ上のフォーム入力だけを補助します。
- 公開前にはソースコードだけでなく、Gitのコミット履歴や作者メールアドレスも別途確認してください。
